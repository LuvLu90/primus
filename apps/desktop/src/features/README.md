# features

按功能划分的界面模块（第 16.3 节）：

| 目录 | 内容 |
|---|---|
| `chat/` | 时间线、输入框、消息操作、工具卡片、确认框 |
| `sessions/` | 会话列表（按项目分组）、会话树 |
| `context/` | 上下文条、固定项 |
| `files/` | 右栏 · 文件预览 |
| `settings/` | 设置页 |
| `update/` | 自动更新：状态订阅（`update-store`）与下载完成后的重启提示（第 3.6 节） |
| `capabilities/` | 能力中心（扩展、技能、提示模板、MCP） |
| `usage/` | 用量统计 |
